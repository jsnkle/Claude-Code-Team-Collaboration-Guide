### Decision: Doc structure

The 10 gaps could be addressed by:
- **Option A**: Expand existing docs (less file churn, keeps doc count at 20)
- **Option B**: Add new focused docs (cleaner separation, doc count grows to ~23)
- **Option C**: Hybrid — add 2-3 new docs for major topics (CI/CD, enterprise admin, hooks guide), fold smaller items into existing docs

Suggested hybrid approach:
1. New `docs/21-cicd-automation.md` — GitHub Actions + GitLab CI/CD + headless mode cross-ref
2. New `docs/22-enterprise-admin.md` — Authentication, LLM gateway, network config, monitoring, analytics
3. New `docs/XX-hooks.md` or expand hooks content in `10-best-practices.md`
4. Fold `model-config` into `04-configuration.md`
5. Fold `devcontainer` into `09-onboarding.md`
